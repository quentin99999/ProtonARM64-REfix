# ProtonARM64-REfix
This is an offshoot of the latest proton Experiemental (as of this posting, 26-10-15) that fixes the crashing you would get while using REframework in games.


## Installation
In desktop mode, download and Unzip, and move to .local/share/steam/compatibilitytools.d. 
Then restart, and in game mode you should see a new compatibility tool.
